# Data dictionary

- `seed`: random seed identifier.
- `policy`: routing policy.
- `p99_fct_ms`: 99th-percentile flow completion time in milliseconds.
- `mlu`: maximum link utilization normalized to link capacity.
- `congestion_probability_pct`: percentage of decision windows above threshold.
- `route_changes`: number of forwarding rule changes installed during the run.
- `control_window_after_shift`: windows elapsed after congestion migration.
- `fidelity_pct`: similarity between repaired and original utilization series.
- `action_rank_agreement_pct`: candidate action-ordering agreement.
